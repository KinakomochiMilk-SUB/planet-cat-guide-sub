SERVER RULES

利用上の注意

参加前に、サーバーのルールを確認してください。

以下はサーバー内のルールを確認するための案内です。 参加後はDiscordのルールチャンネルも確認し、案内メッセージの「member」ボタンを押してください。

ルール一覧

1. 基本ルール
  1. 日本の法律およびDiscordの利用規約を守ってください。
  2. 管理者・スタッフの指示に従ってください。
  3. プロフィールを記入してください。未記入の場合、キックされることがあります。
  4. 長期間活動がない場合、キックされることがあります。自分から退出することもでき、再参加も可能です。
  5. 他のメンバーを尊重し、思いやりを持って接してください。
2. 禁止事項
  1. スパム、荒らし、危険なURLの投稿、過度なメンションは禁止です。
  2. 暴言や喧嘩は禁止です。双方に処分が行われる場合があります。
  3. NSFWチャンネル以外での成人向けコンテンツの投稿は禁止です。
  4. 本人の許可なく、個人情報を公開することは禁止です。
  5. 宣伝・勧誘は禁止です。
  6. 外部で起きたトラブルを持ち込むことは禁止です。
  7. 許可なくフレンド申請・DM・通話を送ることは禁止です。まずメインの雑談チャンネルで許可を得てください。
  8. 配信を行う場合は、ミラー配信など、他者の公衆送信権を侵害しないようにしてください。配信前にメインの雑談チャンネルで許可を得てください。
3. サーバーの運営について
  1. 用途に合ったチャンネルを利用してください。
  2. ルール違反があった場合、ミュート・キック・BANなどの対応を行うことがあります。
  3. オーナーに個別で挨拶する必要はありません。
  4. 久しぶりに戻ってきたメンバーは、温かく迎えてください。
  5. オフ会など、サーバー外での交流は自己責任で行ってください。
  6. お互いに寛容な気持ちを持って接してください。
4. 困ったとき・相談したいとき
  1. 質問や報告は「🗯️ご相談はこちら」から行ってください。
  2. 無断のフレンド申請・DM・通話などで迷惑行為を受けた場合も、「🗯️ご相談はこちら」から報告してください。

参加後の手順

  1. 上のルールを読みます。
  2. Discordのルールチャンネルを開き、案内メッセージ下部の「member」ボタンを押します。
  3. 「プロフィール紹介」チャンネルでプロフィールを投稿します。
  4. 必要に応じて、同じ案内メッセージの「初心者」ボタンを押します。
